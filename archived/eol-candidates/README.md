# Experimental EOL candidates — DO NOT DEPLOY

These ZIPs are generated copies, not the source archive and not a validated release. They contain entry guards (or legacy per-command guards) and the version-specific EOL control functions. None has been validated on a Minecraft server. They do not impose world-wide read-only access, remove persistent data, or clear shared scheduled functions. Original sources and provenance remain elsewhere under `archived/` and in the original repositories.

`manifest.json` records source repository, source commit and path, ZIP SHA-256, guarded function count and mode. `vortaforge-eol.json` inside each ZIP lists the guarded functions and control-plane limitations. A version-aware runtime validation, non-function entry-point review, safe cleanup strategy and actual upstream migration are still required. Do not treat these as complete EOL enforcement.
