# Frozen Vortex source

This tree is the archived source snapshot of Vortex, not a supported installation or an active datapack. Former `.github/` files have been moved to inert `ci-source/`; the source/destination mapping and hashes are in `docs/CONSOLIDATION-SOURCES.json` at the repository root. The original main history is a merge parent and all observed Git refs are recoverable from `recovery/vortex.bundle`.

The two unchanged release ZIPs in `release-assets/` are historical recovery copies, not a recommendation to install them. GitHub release records, issues, pull requests and Actions data are not recreated by copying these files. Existing installed packs are unaffected, and the staged EOL implementation is not part of this migration.
